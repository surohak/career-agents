# Career workspace index

Read this first. One line per file, then open only what the task needs.

- identity.md: who the person is, current role, contact policy, links.
- voice.md: how they write, words to use and avoid, sentence rules.
- constraints.md: hard limits (never post, never leak, never invent).
- positioning.md: target roles, keywords, headline options, differentiators.
- cv-canonical.md: the CV text as the single source of truth for facts.
- accepted.md: LinkedIn vs CV differences that are intentional and must not be reported again (ignored when rules.word_perfect is true).
- decisions.md: content decisions (aliases, owners, banned claims, fixed wording, per-surface differences). Every drafting skill reads it.
